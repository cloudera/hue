Call Hue from your own code with one of these interfaces.

## REST

Run queries, manage files, import data and administer connectors over HTTP. Read the [REST API](/developer/api/rest/).

## Python

Run code in the Hue shell on the server, for example to manage users and documents. Read the [Python API](/developer/api/python/).

The JavaScript API from the [NPM package](/developer/components/) is not documented yet.
